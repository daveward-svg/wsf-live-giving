# WSF Make Room Live Giving

Live fundraising display for Winston Salem First's **Make Room** campaign.

- Goal: $300,000
- Firebase Realtime Database live updates
- Firebase email/password admin login
- Netlify-ready static site
- Public display: `/`
- Admin: `/admin.html`
- Giving link: https://app.easytithe.com/App/Giving/wsf

## Campaign database path
`campaigns/make-room`

The existing Firebase project and authentication configuration are preserved. The campaign uses a new database node so the completed Rainforest Falls data remains separate.
